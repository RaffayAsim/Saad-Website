# Saad Website

Premium 3D interactive personal/brand site for **Saad Zain**.

**Live:** [saadzain.net](https://saadzain.net/)

## Stack
- React + TypeScript + Vite
- Three.js / React Three Fiber + postprocessing
- Tailwind CSS + shadcn/ui
- Framer Motion / GSAP / Lenis smooth scroll
- Built with Lovable + vibe coding workflows

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```
